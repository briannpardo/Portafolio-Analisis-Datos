# 🚀 Mi Portafolio de Ciencia de Datos

¡Hola! Soy Brian Pardo y aquí presento mis proyectos de análisis de datos y machine learning utilizando Python. Este portafolio demuestra mi capacidad para transformar datos crudos en soluciones predictivas y estratégicas.

## 📁 Proyectos Destacados:

1. **[Análisis de Ventas ElectroTech](./01_ElectroTech):** * Limpieza de datos y visualización de tendencias de ventas retail.
   * Uso de Pandas y Matplotlib para identificar picos de demanda.

2. **[HR Analytics - Caso IBM](./02_HR_Analytics):** * Estudio profundo sobre la rotación de personal (Attrition).
   * Identificación de factores críticos de negocio como el impacto de las horas extra y brechas salariales.

3. **[Predicción de Rotación con Machine Learning](./03_ML_Retention_Prediction):** * Implementación de un modelo **Random Forest** con una precisión del **81%**.
   * Análisis de importancia de variables para predecir proactivamente el abandono laboral.
   
4. **[SQL Business Queries](./04_SQL_Business_Queries):** Diseño de base de datos y consultas de inventario para toma de decisiones.
